### Week 5 achievements

* Gained a solid understanding of authentication and authorization using **Amazon Cognito**, including the roles of **User Pools** and **Identity Pools** in user management and access control.

* Practiced implementing and validating user authentication with **Amazon Cognito**, gaining an understanding of the interaction between the application, **Amazon Cognito**, and **Amazon API Gateway**.

* Learned how to use **Amazon CloudWatch** for system monitoring, including collecting **Metrics**, managing **Logs**, configuring **Alarms**, and visualizing operational data with **Dashboards**.

* Understood how **Amazon CloudWatch** supports monitoring AWS resources, troubleshooting issues, and analyzing system behavior during application development.

* **About the group project:**

    * Evaluated the integration between **Amazon API Gateway**, **Amazon Cognito**, **Amazon CloudWatch**, and **Amazon DynamoDB**, gaining a clearer understanding of the request-processing workflow and the security architecture of the system.

    * Participated in evaluating and selecting a frontend design that meets the project requirements while providing a responsive user experience across desktop and mobile platforms.

    * Refined the API design based on the authentication and monitoring mechanisms, improving the consistency between the system design documents and the implementation.
